ONVIF Camera Client 1.0.0 — релизный пакет для Astra Linux 1.8 (x86_64)

Запуск:  ./run.sh

Возможности:
  * WS-Discovery (ONVIF) поиск камер в локальной сети
  * Добавление камер вручную по RTSP URL
  * Мультипросмотр до 4 потоков (сетка 1x1 / 2x2), декодирование FFmpeg

Пакет самодостаточен: все библиотеки (Qt5, FFmpeg) лежат в ./lib,
плагины Qt — в ./plugins. Системные Qt/FFmpeg устанавливать не нужно.
Требуются только базовые системные библиотеки (glibc, X11), входящие в Astra 1.8.
