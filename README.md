# ONVIF Camera Client

Клиент IP-камер для **Astra Linux 1.8 (x86_64)**: ONVIF-поиск в локальной сети,
многопоточное видео, хранилище настроенных камер, полноэкранный режим.

## Что нового в v2.1
- 🎨 **Современный тёмный дизайн**: читаемые кнопки (светлый текст на градиенте, крупный шрифт),
  стилизованные списки/поля/меню/скроллбары, шапка приложения с названием
- 🖌 **Сменные темы**: файл `themes/style.qss` правится без пересборки;
  запуск своей темы: `onvif-client --theme моя_тема.qss`
- ⬆ Улучшенный установщик: тема ставится в `/usr/share/onvif-camera-client/themes`,
  меню-запуск (`Exec=onvif-client`) работает из PATH через launcher-скрипт

## Возможности (v2.x)
- **ONVIF WS-Discovery** — поиск камер в локальной сети + список потоков (main/sub)
- **Шаблон поиска** — ручная камера по IP/порту с логином и паролем (Basic/Digest),
  сканирование подсети по шаблону
- **Хранилище камер** — сохранение/выбор/редактирование/удаление, JSON в `~/.config/local/onvif-client/`
- **Мультипросмотр** — сетки 1×1, 2×2, 3×3, 4×4, 3×6, 6×3 (до 18 потоков)
- **Полноэкранный режим** — кнопка, F11, выход Esc
- **Автостарт с профилем** — `--profile "Двор,Вход" --fullscreen`
- **Установка в систему** — `./install.sh`: команда `onvif-client` в PATH, пункт меню
  «Камеры ONVIF» с иконкой камеры

## Быстрый старт (готовый пакет)
```bash
tar xzf onvif-camera-client-2.1.0-astra1.8-x86_64.tar.gz
cd onvif-camera-client-2.1.0
./run.sh                       # запуск без установки
sudo ./install.sh              # установка в систему (иконка в меню, onvif-client в PATH)
```
Пакет **самодостаточный**: Qt5, FFmpeg/libav и плагины включены — системные пакеты не нужны.

## Командная строка
```
onvif-client [options]
  -p, --profile <имена>   Подключить сохранённые камеры (через запятую или повторно)
  -f, --fullscreen        Запустить в полноэкранном режиме
  -t, --theme <file.qss>  Файл темы оформления
      --version / --help
```

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| F11 | Полный экран / выход |
| Esc | Выход из полноэкранного режима |

## Сборка из исходников
```bash
sudo apt install qtbase5-dev libavformat-dev libavcodec-dev libswscale-dev cmake g++
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/onvif-client
```
Зависимости: Qt5 (Widgets, Network), FFmpeg/libav (для Astra 1.8 — штатные пакеты).
