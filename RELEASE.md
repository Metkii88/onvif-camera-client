# Release v2.3.0 — масштабирование сетки + профили камер

## Изменения относительно v2.2

### 🖱 Масштабирование сетки при ресайзе и в полном экране
- Сетка камер корректно перестраивается при изменении размера окна, а также
  при входе/выходе из полноэкранного режима (FS-сетка масштабируется на весь экран).
- После изменения размера видеоячейки потоки автоматически перезапускаются,
  поэтому картинка занимает новый размер ячейки, а не остаётся в старом.
- **Перемещение окна больше не «дёргает» видео**: дебаунс-таймер (250 мс)
  срабатывает только при реальной смене геометрии сетки.

### 💾 Профили сетки (наборы камер)
- Новая вкладка **«Профили»**:
  - «💾 Сохранить сетку как профиль» — запоминает все подключённые камеры,
    их позиции в сетке и раскладку (колонки);
  - двойной клик по профилю или «▶ Загрузить» — мгновенно собирает сетку заново;
  - «✏ Переименовать», «🗑 Удалить»;
  - «▶▶ Запустить выбранный профиль в полном экране» — загрузка + F11 одной кнопкой.
- Хранилище: `~/.config/onvif-client/profiles.json` (атомарная запись).
- Для сохранённых камер при загрузке берутся актуальные реквизиты из хранилища.

### 🔁 Автовосстановление состояния
- При закрытии программы запоминаются размер/позиция окна, пресет раскладки
  и имя последнего профиля; при следующем запуске всё восстанавливается
  (профиль загружается автоматически).

## Сборка
```bash
sudo apt install qtbase5-dev libavformat-dev libavcodec-dev libavutil-dev libswscale-dev pkg-config
cmake -B build && cmake --build build -j$(nproc)
```
